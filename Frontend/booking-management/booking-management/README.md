# Booking Management

A simple Level Placement Test Booking Management frontend built with Next.js and React.

## Features

- Booking List page
- Create Booking form
- Update Booking form
- Add, edit and update booking information
- Booking data saved in browser localStorage
- Payment slip filename shown after upload
- Time shown as `10:00 AM`
- Components are written in `.js` files

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
